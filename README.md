# DOTPOND

Windows を主対象とするドットアニメーション壁紙と、ログイン不要のブラウザー設定画面。
参考: https://www.daoho.dev/ 。参考サイトのコード・画像は流用せず数式で描画する。

## 仕様

- 黒を基調とした Liquid Glass の操作パネル。キャッチコピーや販促画面なし。
- 鯉の池、波、星雲の3シーン。速度・ドットサイズ・明るさ・色・一時停止を操作できる。
- 初期ロードは全画面スケルトン。動きを減らすOS設定では停止状態で開始する。
- PNG/JPEG/WebP の画像を端末内でドット化。最大15MB、最大2400万画素。画像と音声はサーバーへ送らない。
- ブラウザーの音声連動は画面/タブ共有の音声、またはマイクを明示的に開始して使用する。共有音声が無ければエラーを表示して映像トラックも破棄する。
- Windows アプリは Electron。トレイ常駐、壁紙の開始/停止、全画面表示、終了。PC音声は Windows loopback を利用する。
- 背景への埋め込みは Windows WorkerW に依存する。失敗時は通常プレビューに戻せる。まずプライマリ画面に対応。自動起動・レジストリ変更・ロック機能は付けない。
- ブラウザー版は全画面鑑賞が可能。ブラウザーのみではデスクトップ背面への常駐はできない。
- 設定を localStorage に保存。画像は保存せず、再起動時は画像シーンから鯉に戻す。設定保存が使えなくても操作可能。
- ウィンドウ非表示時は描画を止める。描画は30fps上限、canvas解像度に上限を設ける。
- キーボード: Space 再生/停止、F 全画面、H パネル表示/非表示、Escape パネル復帰。入力欄でのショートカットは発火させない。
- Cloudflare Pages で静的配信。既存の公開権限に合わせる。サーバー保存・ログイン・AIが不要なためDBとWorkers AIは追加しない。
- Windows版では音声レベルと読み込んだ画像を壁紙ウィンドウへ端末内IPCで共有する。画像はメモリのみ。外部ページへの遷移や任意コードの実行は許可しない。

## 開発手順・検証

仕様 → `node --test` による描画モデル・入力検証・設定復元のテスト → 最小実装。
ブラウザー実操作でシーン、設定、停止、画像、音声のエラー処理、全画面、キーボード、再読み込みを確認する。
Windows固有の壁紙/音声はブラウザーテストとは別に確認する。未確認の項目は合格扱いしない。

## コマンド

- `npm test`: モデルとローカルサーバーのテスト
- `npm run dev`: http://127.0.0.1:4173
- `npm start`: Windowsアプリ
- `npm run package`: Windows配布物を生成
- `npm run deploy`: Cloudflare公開

検証結果と公開先は作業完了時に追記する。
